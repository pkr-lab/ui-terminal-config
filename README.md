# ui-terminal-config

Ein Skript für Ubuntu Desktop: installiert den Prompt Starship mit Konfiguration, die JetBrainsMono Nerd Font und optional KI-Kommandozeilenwerkzeuge.

## Quickstart

```sh
git clone https://github.com/pkr-lab/ui-terminal-config.git ~/ui-terminal-config
cd ~/ui-terminal-config
./install.sh
```
